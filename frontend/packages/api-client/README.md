# @homebook/api-client

TypeScript client for the HomeBook backend. Every call to the backend goes through this package.

- `src/generated/` is generated by Kiota from `backend/HomeBook.Backend/HomeBook.Backend.json`. **Never edit it by hand.**
- `src/index.ts` and its siblings are the hand-written, stable surface: `createBackendClient`, the
  status-code error predicates, `resolveMediaUrl`, `toBase64Content` and the helpers that hide the
  backend's quirks.

## Regenerate

From the repository root, after any change to a backend endpoint, route or DTO:

```
./scripts/generate-clients.sh
```

The script regenerates the OpenAPI document from a running backend and both the C# and the
TypeScript client.

## Scripts

| Command             | Purpose                              |
| ------------------- | ------------------------------------ |
| `bun run build`     | Library build with tsup into `dist/` |
| `bun run test`      | Vitest with a mocked `fetch`         |
| `bun run typecheck` | `tsc --noEmit`                       |

Errors carry the HTTP status code. Branch on it, never on the response body.
